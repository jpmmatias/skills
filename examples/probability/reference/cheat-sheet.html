Vocabulary

Var(X), σ², σVariance E[(X − μ)²] = E[X²] − μ²; standard deviation σ = √Var(X).2
standard errorThe standard deviation of an estimate; for a mean of n independent draws, σ/√n.2

base rateHow common the condition is before testing (prevalence, prior).3
sensitivity / specificityP(+ | condition) / P(− | no condition). False-positive rate = 1 − specificity.3

Rules of thumb

  1. Check a PMF adds up to 1 before using it; a total that is off means a missing or double-counted outcome.
  2. Seed every simulation and print the seed, so a surprising run can be repeated.
  3. A short streak is swamped, not corrected: draws have no memory. This holds only for independent draws.
  4. Four times the data halves the noise (σ/√n). It breaks when observations are not independent, such as several sessions from one user.
  5. Before trusting a positive, ask for the base rate. Translate to counts out of 1,000 or 10,000 and count the false positives. When the condition is rare, specificity matters more than sensitivity.
