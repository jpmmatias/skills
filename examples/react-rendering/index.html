Course

React Rendering Internals

Three lessons for frontend developers who want to stop guessing why components re-render: what React does when it renders, how a state update spreads through the tree, and which effects and memoization tricks actually change anything. Taught for React 19, with version notes where React 18 differs.

This is a shipped example course: the mission describes a typical learner, not a real person. Interactive figures are simplified models of the rules the lessons teach, labelled as such.
