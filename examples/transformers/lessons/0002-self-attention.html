Lesson 2 · Compute one attention head

Self-attention

After lesson 1, every token is a vector that knows only itself and its position. Attention is the step where each token's vector takes in information from the other tokens.

Why this matters for your mission: attention is where a word like “it” in your prompt gets connected to what it refers to, and its causal mask is the reason a model can only write left to right, one token at a time, which is what you see when a reply streams.

query (q)What this token is looking for, as a vector.
key (k)What each token offers to be found by, as a vector.
value (v)What each token hands over if it is attended to.
softmaxTurns any list of scores into positive weights that add up to 1: exponentiate each, divide by the total.

One query, many keys

The Transformer paper describes attention as mapping a query and a set of key–value pairs to an output: the output is a weighted sum of the values, and each value's weight comes from how well the query matches that value's key78. In self-attention all three come from the same sequence: every token's input vector is multiplied by three learned matrices, WQ, WK and WV, to give its own q, k and v11. For all queries at once, stacked as rows of matrices8:

Attention(Q, K, V) = softmax( Q·Kᵀ / √dk ) · V

Here dk is the length of each key vector. Read it right to left for one query: dot the query with every key, divide by √dk, softmax, then use the weights to average the values.

The toy sentence

To compute this by hand we need small vectors. The ones below are toy numbers, chosen by hand so the pattern is easy to read: dk = 4 and values have 2 dimensions. You can read the four key dimensions loosely as “a thing”, “an action”, “a small word”, “a pronoun”. That reading is our design; a trained head learns its own numbers, and nobody writes them down like this.

Worked example: what does “it” attend to?

Query: q(it) = [2, 0, 0, 0.5]. In a decoder, “it” (position 4) may look only at positions 0–4; the next section explains why. √dk = √4 = 2.

The output for “it” is the weighted average of the five visible values:
0.078·[0.1, 0.1] + 0.578·[0.9, 0.8] + 0.078·[0.2, −0.8] + 0.078·[−0.6, 0.1] + 0.188·[−0.2, 0.7] ≈ [0.46, 0.55].
The new vector for “it” now carries mostly what “cat” offered. That is the whole trick: a token's vector is rebuilt from the values of the tokens its query matches.

Why does the ÷ √dk line exist? If the components of q and k are independent with mean 0 and variance 1, their dot product has variance dk, so scores grow with the vector size. The authors suspected that large scores push the softmax into regions where its gradients are extremely small, and scale by 1/√dk to counteract it78. With the original model's dk = 64, that means dividing by 811.

Things to try: “The” with the mask on (it can only attend to itself, so its weight is 1); “The” with the mask off (it reaches forward to “cat”, a token a decoder would not have yet); “was” (it finds “it”).

The causal mask

A decoder-only model such as GPT-2 is trained to predict each next token from the ones before it, at every position of a training text at once. If position 4 could read position 5, it could copy the answer. So decoder self-attention masks every later position: their scores are set to −∞ before the softmax, which makes their weights exactly 07811. GPT-2's code builds a lower-triangular mask and subtracts 1010 from the blocked scores, which has the same effect5.

Many heads at once

A real layer runs several attention heads side by side, each with its own WQ, WK, WV, and concatenates their outputs. The original base model used 8 heads with dk = 64 each, over 512-wide vectors78; GPT-2's code defaults to 12 heads over 768 dimensions, again 64 per head5. Each head does exactly what you computed above.

Milestone challenge

One head, by hand, on your own phrase

Take a 4-token phrase from one of your own prompts (tokenize it as in lesson 1). Give each token toy vectors: q and k with dk = 2 or 4, and a 2-D v. Choose them so that one token should clearly attend to another, and say which before you compute. Then compute one causal attention head for two queries, the last token and the second token, in a spreadsheet or in plain code without a library attention function. Finally, run the last token once more without the ÷ √dk.

What to send back

Your vectors, your prediction, a table per query (q·k, scaled score, weight, output), the spreadsheet or code, and the no-scaling run.

Pass criteria

  1. For both queries the table shows q·k, the score divided by √dk and the softmax weights, and each query's weights add up to 1.00 (± 0.01).
  2. The second token's row gives weight 0 to positions 2 and 3 (masked); the last token's row uses all four positions.
  3. Each output vector equals the sum of weight × value, with the arithmetic written out for at least one component.
  4. The no-scaling run reports the largest weight with and without ÷ √dk, next to your written prediction from before the run.

When you are done, send your work to your teacher in the terminal.
