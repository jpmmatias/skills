Learncraft · Example courses

What a course looks like

Learncraft turns an AI coding agent into a teacher that writes the course to your own folder. These three courses use the same files and runtime it produces: a dashboard, short lessons, practice, a review page and sources.

Example course — no learner data. These courses were written by hand to Learncraft's lesson format to show its output; they are not a recording of an agent session. The milestones belong to a made-up learner, and nothing has been answered yet. Practice you do here is saved only in this browser.

  1. How Transformers Work

    What happens inside the LLM you call through an API, from your prompt to each token of the reply.

    Lessons
    From text to vectors · Self-attention · Blocks and generation
    Interactive
    A positional-encoding explorer, an attention explorer with a causal-mask grid, a step-through decoder block, a narrated motion scene of generation one token at a time, and a temperature explorer
    For
    Developers who use LLM APIs; vectors and dot products, no calculus

    Open the course →Review page

  2. React Rendering Internals

    Stop guessing why components re-render: predict what React does after a state update, and back every fix with evidence.

    Lessons
    What “render” means · How a state update spreads · Effects, Strict Mode and memoization
    Interactive
    Step-through flow diagrams of trigger → render → commit, and a render simulator that shows which components render after a state update, with and without memo
    For
    Frontend developers working in React 18 or 19

    Open the course →Review page

  3. Probability & Statistics, by experiment

    Reason about randomness in A/B tests and dashboards: simulate it, measure its noise, and weigh evidence against base rates.

    Lessons
    Distributions and sampling · Expected value and variance · Conditional probability and base rates
    Interactive
    A sampler that draws from a distribution you define, a sample mean that narrows as n grows, and a natural-frequency tree for base rates
    For
    Developers who read experiment dashboards; high-school algebra

    Open the course →Review page

Make your own

In Claude Code:

/plugin marketplace add jpmmatias/skills
/plugin install learn@jpmmatias

Then, in an empty folder, run /learn:learn <topic>. Other agents and install methods, the guide and the source are in the jpmmatias/skills repository.
