Cheat sheet

The whole path from your prompt to one streamed token, on one page. Sizes are GPT-2 small's, from its released code, unless a row says otherwise.

The path of one step

text → tokens → ids (BPE tokenizer) ids → wte rows + wpe rows 5 tokens → 5 × 768 12 × block: x = x + attn(ln_1(x)) x = x + mlp(ln_2(x)) ln_f, then × wteᵀ 5 × 50,257 logits last row ÷ T → softmax → sample one new token append, repeat until the length limit (APIs also stop at an end-of-text token, 50256 in GPT-2)

Vocabulary

TermMeaningLesson
tokenThe unit the model reads and writes: a word, part of a word, a space plus a word, a symbol.1
BPEByte pair encoding: learn a vocabulary by repeatedly merging the most frequent adjacent pair. GPT-2: 256 bytes + 50,000 merges + 1 end token = 50,257.1
embeddingA learned row of a table, looked up by id. GPT-2: wte (tokens, 50,257 × 768), wpe (positions, 1,024 × 768).1
positional informationLearned table added to the input (GPT-2); fixed sinusoids added (2017 original); queries and keys rotated by position (RoPE, e.g. Llama).1
q, k, vQuery, key, value: each input vector times learned WQ, WK, WV.2
d_kLength of a key (and query) vector per head. 64 in the 2017 base model and in GPT-2 small.2
causal maskScores of later positions set to −∞ before the softmax, so a token sees only itself and earlier tokens.2
headOne attention computation. A layer runs several (8 in the 2017 base model, 12 in GPT-2 small), concatenates them, then multiplies by a learned output matrix WO.2
residual streamEach token's running vector; every sub-layer adds its output back onto it.3
pre-LN / post-LNNorm before each sub-layer (GPT-2, Llama with RMSNorm) or after the residual add (2017 original).3
logitsOne raw score per vocabulary token, at every position; generation uses only the last position's.3
temperatureDivides the logits before the softmax. T < 1 sharpens, T > 1 flattens, T → 0 is greedy.3

Rules of thumb

  1. A token count only means something together with its tokenizer: the same text can give different counts under different encodings (lesson 1 shows 8 vs 5).
  2. For OpenAI's encodings a token is about 4 bytes of text on average (tiktoken README). It is an average: lesson 1's Portuguese greeting costs GPT-2 far more tokens per word than English.
  3. A leading space belongs to the word that follows it, so ␣word and word are different strings to the tokenizer and can split differently (lesson 1: ␣strawberry is 1 token, strawberry is 3).
  4. Each query's attention weights add up to 1; the output is a weighted average of values, so it stays inside the range of the values it mixes.
  5. In a decoder, position i attends to positions 0…i. When generating, only the last position's logits are used to pick the next token (every position predicts its own next token, which is how training works).
  6. In plain decoding, a reply of N tokens is N runs of the loop, one sampled token each.
  7. Temperature changes how spread out the probabilities are, never their order.
